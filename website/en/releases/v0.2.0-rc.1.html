Release notes/v0.2.0-rc.1

RELEASE NOTES

v0.2.0-rc.1

2026-10-14

Adds a world read-only view authenticated with the world ID and applied game password.

Features and fixes

  • Pages now explains sharing worlds with friends, including host and visitor steps for downloading existing snapshots without administrator accounts, network access requirements and plain ZIP contents.
  • Independent visitor sessions with fixed expiry, password/world change revocation and login rate limits. Empty game passwords do not enable access.
  • Persistent basic information and URL-based settings, backups and logs tabs, with search by Chinese label or field name. Settings show observed current values and catalog defaults; missing observations remain unknown.
  • Downloads export only world and player saves from existing matching offline backups, with ownership, manifest and checksum validation. Administrative configuration and credentials are excluded.
  • Shared administrator and visitor login layout, instance read-only links, parameter dialog draft persistence and shared validation bounds and choices.
  • Fixes list-valued runtime settings and ANSI log escapes. Annotation style compatibility is restricted to the explicitly enabled local test browser source.
  • New instances publish game UDP on all IPv4 interfaces while management REST/RCON remain on loopback. This release does not automatically rebuild existing instances.

Upgrade and verification

Back up management state, master key, deployment configuration and game saves; resolve active tasks and retain matching previous binaries or images for rollback. Windows program-only upgrades and Linux persistent mounts retain instance data. A game upgrade is not required.

Local verification passed 231 non-Desktop backend tests, 152 frontend tests, build, formatting and documentation checks. Isolated Docker real-game verification covered settings, redacted logs and save export checksums. Browser verification covered login, tabs, search and defaults.

Release CI, cross-platform packages and Pages are verified by the tag workflows. No production deployment, external gameplay connectivity or real-client character recovery is claimed. Windows installers are unsigned. Access remains restricted by the source IP allowlist; visitor authentication does not grant administrator access.

Assets

Linux x64 Docker archive, Windows x64 self-contained ZIP, Windows x64 Inno installer and SHA256SUMS.
