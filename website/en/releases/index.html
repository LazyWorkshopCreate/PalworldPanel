2026-10-06

v0.1.0-rc.1

This is the first PalworldPanel release candidate for managing multiple Palworld instances on a single server. The panel runs as a Windows service or Linux container, while game instances run in Docker Linux containers. The console supports world creation, settings changes, backups, recovery and daily maintenance.
