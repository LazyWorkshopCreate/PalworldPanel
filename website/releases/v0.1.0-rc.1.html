RELEASE NOTES

v0.1.0-rc.1

2026-10-06

这是 PalworldPanel 的首个候选版本，面向单台服务器提供幻兽帕鲁多实例管理。面板支持 Windows 服务与 Linux 容器部署，游戏实例统一通过 Docker Linux 容器运行，可在控制台完成世界创建、参数调整、备份恢复和日常维护。

主要内容

  • 创建独立世界或受控接管已有实例，各自使用独立目录、存档、密码、端口、备份和任务锁。
  • 实例列表显示游戏连接 IP、UDP 端口、游戏版本和资源配置；详情展示运行状态、玩家数、FPS 与资源用量。
  • 白名单内可匿名查看只读仪表盘，首次访问设置面板管理员密码，登录后才能执行管理操作。
  • 游戏参数支持中文名称与字段搜索，对照当前值、默认值和草稿值；修改在弹窗中完成，未应用的草稿高亮提示。
  • 游戏管理密码和访问密码支持手动输入、随机生成及草稿保存，只显示设置状态，不回显已有密码。
  • 实例初始化和维护通过后台任务执行，展示阶段与结果；实例操作二次确认，应用配置期间防止重复提交，日志按最新内容优先显示。
  • 提供每日定时备份、手动离线备份、受控恢复、恢复点加密导出和世界 ZIP 导入。
  • Windows 安装器提供重新配置和仅升级程序两种模式，检查 Docker、监听地址与端口，并通过完整程序目录交换避免旧文件残留。
  • 提供中英文产品网站、功能说明、使用指南和发布日志，功能说明配有脱敏控制台截图。
  • 建立 Linux/Windows 测试、按版本标签构建发行包与部署 GitHub Pages 的流水线。

生命周期验收修复

  • 新建预览检查磁盘余量，空间不足时不留下失败实例或任务。
  • 实例存在排队、执行中或待处理任务时，统一锁定写操作，完成或明确处理后释放。
  • 修复 Windows 隔离清理和最终清空被实例目录内锁文件阻塞的问题。
  • 修复附加参数已应用后仍被判定为草稿、无法执行升级的问题。
  • 备份列表按创建时间倒序排列，避免随机标识导致顺序混乱。
  • 修复空技术列表的校验及写入表示，支持已知模板取消接管后的重新登记与写管理接管。
  • 接管回退后重新核对旧容器是否存在，避免失效的登记 ID 阻止后续接管。

升级与兼容性

  • Windows 已安装面板选择“仅升级程序”，保留配置、管理员账号和实例数据；需要调整部署参数时选择“重新配置”。升级前备份管理数据和游戏存档。
  • Windows 默认使用 HTTP，并支持本机回环访问；Linux 部署按项目配置准备 TLS、持久化目录和 Docker socket 权限。
  • 游戏连接使用实例显示的 IP 与 UDP 端口，不能通过浏览器访问游戏端口。管理接口仅面向明确白名单中的内网地址，不直接公开。
  • 世界 ZIP 导入保留目标实例的密码、端口和规则，不承诺单机、合作主机或跨平台玩家身份自动迁移。

验证与限制

  • 已有后端、前端及本机 Docker Desktop 场景验证记录，覆盖实例隔离、参数应用、任务互斥、备份恢复与 Windows 部署流程；详细结果见仓库验证文档。
  • 这是候选版本，目标环境安装、真实游戏客户端连通和玩家恢复仍需按实际部署验收；管理 API 健康不能替代游戏连接验证。
  • Windows 安装包未做代码签名。面板具有本机 Docker 管理权限，应按部署说明配置精确 IP 白名单与防火墙。
  • 公网 UDP 转发与诊断不属于面板管理范围；管理控制台当前使用中文。

发布资产

  • Linux x64 Docker 面板镜像归档
  • Windows x64 自包含程序 ZIP
  • Windows x64 Inno 安装包
  • SHA256SUMS 校验清单

部署前请阅读使用指南，并使用 SHA256SUMS 校验下载文件。Windows 安装和目录交换升级优先使用安装包，程序 ZIP 用于手工部署。
