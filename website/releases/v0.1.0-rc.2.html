RELEASE NOTES

v0.1.0-rc.2

2026-10-07

新增控制台 URL 路由和游戏更新检查，完善实例操作反馈与互斥锁。内存准入改为按实时可用容量检查，并修复 Linux 接管、维护后恢复启动和配置漂移误报。支持从 rc.1 保留管理数据升级。

新增与改进

  • 控制台支持 URL 路由，仪表盘、实例、主机与安全及实例各页签均可直接访问，支持刷新、前进和后退。
  • 统一实例操作的功能说明、状态判断和互斥锁。排队、执行或待处理任务期间停用冲突操作，完成或明确处理后释放。
  • 改善“更多”菜单的点击反馈，菜单左对齐并缩小宽度；实例操作继续使用二次确认。
  • 升级先检查版本，无更新时明确提示；有更新时显示当前和目标版本，隐藏镜像与安装构建等技术字段。升级校验目标安装和启动版本，并保留配套恢复点。
  • 内存展示分为使用中、已分配和总内存；新世界创建与显式启动按实时可用内存、系统预留和其他启动任务预约检查，停止实例配额不重复占用预算。

修复

  • 修复内网 HTTP 下浏览器缺少 crypto.randomUUID 时，实例操作无法提交的问题，使用安全随机生成 UUID 回退。
  • 修复 Linux 新实例目录尚不存在时的磁盘检查失败，以及 host 网络容器缺少端口映射导致的扫描错误。
  • 受控接管支持既有 UDP 通配绑定和未配置查询端口的模板，保留宿主游戏端口与已有转发方式，管理接口仍仅回环访问。
  • 修复运行实例备份或维护后，因重复申请完整内存配额而无法恢复启动的问题。未增加内存限额的维护沿用原运行分配，新建及显式启动继续完整检查。
  • 修复游戏停服重写 INI 数字或布尔格式被误判为外部配置变化的问题。配置指纹继续检测真实参数、密码、未知字段和其他配置段的变化；旧指纹仅在配置未变化且无活动任务时安全迁移。
  • 改善后端异常诊断，只记录异常类型和调用位置，不记录请求内容或可能包含秘密的异常消息。

升级与兼容性

  • 升级前备份面板 state/private、主密钥、部署配置及游戏存档，并确认没有执行中或待处理任务。保留旧镜像或安装包以便回退。
  • Windows 使用安装包的“仅升级程序”，保留管理员账号、部署配置和实例数据；需要修改部署参数时选择“重新配置”。
  • Linux 导入新镜像后更新面板部署的镜像版本并重建面板容器，保留持久化目录和挂载。已有游戏实例无需随面板发行升级游戏版本。
  • 新配置指纹启用后回退到 rc.1 前，应恢复配套旧管理状态；不要仅换旧程序而继续使用升级后的数据库。
  • 这是候选版本，管理控制台仍为中文；内网白名单和管理接口回环限制保持不变。

验证与限制

  • 后端 Windows 与 Linux 各 163 项测试、前端 99 项测试通过，完成 TypeScript/Vite 构建、格式与文档检查。
  • 在真实 Linux 环境使用 API 和网页验收新建、参数及密码草稿应用、备份、恢复与回退、ZIP 导入、加密导出、克隆、隔离撤销、保留数据移除容器、取消和重新接管。
  • 两台既有 Linux 服务器完成写管理接管，核实世界、游戏密码、游戏规则、端口和资源限额保留；定时备份由面板统一维护。
  • 实际并发验证维护恢复不重复申请原内存配额；实际网页验证应用锁定与任务完成后的释放，以及内网 HTTP 操作提交。
  • 真实游戏客户端登录、原玩家角色恢复、跨版本游戏升级、保护期满后的永久删除及整机重启恢复尚未验证。API 健康不能替代玩家连接验证。
  • Windows 安装包未做代码签名，公网 UDP 转发与诊断不属于面板范围。
