CHOOSE HOW YOU RUN IT

One panel, two deployment options.

Windows

Inno installer

The panel runs as a Windows service. Game instances run on the Docker Desktop Linux engine.

  1. Install and start Docker Desktop, select Linux containers and verify Compose v2.
  2. Get the pipeline-built installer and configure a private-network address, port and allowed IPs.
  3. Set the administrator password on first console access, then create or take over an instance.
Get a release ↗Downloads become available when released. Source and release packages currently require GitHub repository access.

Linux

Docker container

The frontend and backend ship in one panel image. Docker Compose manages independent game containers on the host.

  1. Prepare Docker Engine and Compose v2; check disk space and resource budgets.
  2. Build the panel image from source and configure persistent directories, the private-network allowlist and TLS.
  3. Mount dedicated data directories and the Docker socket, then initialize and open the console. 
docker build -f deploy/Dockerfile -t palworldpanel:local .
The panel requires host root and Docker administration privileges.
