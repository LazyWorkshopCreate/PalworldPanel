选择适合你的运行方式

一个面板，两种部署方式。

Windows

Inno 安装包

面板作为 Windows 服务运行，游戏实例仍由 Docker Desktop 的 Linux 引擎承载。

  1. 安装并启动 Docker Desktop，切换到 Linux containers，确认 Compose v2 可用。
  2. 获取流水线生成的安装包，配置内网地址、端口和允许访问的 IP。
  3. 首次访问控制台设置管理员密码，然后创建或接管实例。
获取发行版本 ↗版本发行后可下载；当前源码与发行包需 GitHub 仓库访问权限。

Linux

Docker 容器

前后端打包为一个面板镜像，使用 Docker Compose 管理本机的独立游戏容器。

  1. 准备 Docker Engine 与 Compose v2，检查磁盘空间和资源预算。
  2. 从源码构建面板镜像，配置持久化目录、内网白名单及 TLS。
  3. 挂载独立的数据目录与 Docker socket，完成初始化后访问控制台。 
docker build -f deploy/Dockerfile   -t palworldpanel:local .
面板需要宿主 root 与 Docker 管理权限。
