# 实例更新需求

日期：2026-10-07（北京时间）。状态：已实现，实际验收见验证记录。对应 REQ-19。

- REQ-19.1 点击升级先检查正式版本；无更新明确提示“不需要更新”，不能提交空升级任务。
- REQ-19.2 有更新显示当前版本、目标版本及停服备份影响，不要求选择镜像、升级范围或填写版本。
- REQ-19.3 检查失败必须允许重试，不能误报最新；无法确认目标版本时不允许升级。
- REQ-19.4 继续升级需二次确认，提交后保持实例互斥锁。过期结果、实例变化或新目标出现需要重新检查。
- REQ-19.5 保存进度、停服、备份旧安装与存档，再更新、验证安装和启动结果；失败保留恢复点及处理入口。
- REQ-19.6 保持其他世界运行状态，原先停止的实例验证后保持停止。真实玩家入服仍需管理员确认。

本需求替代原升级弹窗的手动范围、镜像和预期版本输入；其他生命周期及恢复需求不变。
