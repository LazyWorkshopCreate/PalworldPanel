# 世界密码只读实例详情需求

版本日期：2026-10-14。修订日期：2026-10-14。状态：已采纳，工程验证见验证记录。适用范围：内网白名单内的实例访客。替代来源：无，增量扩展现行 MVP。

## REQ-24 访客只读详情

访客输入世界 Id（32 位十六进制 GUID，可输入带连字符 GUID）和当前已应用的游戏连接密码，无须管理员账号，即可查看对应实例的基本信息、游戏设置、最近脱敏日志和同世界备份，并下载世界存档 ZIP。世界 Id 可以出现在分享地址，密码只通过请求正文发送，不进入 URL、浏览器持久存储或日志。没有已应用配置、没有游戏密码、世界未知、世界对应多个实例、实例隔离或删除时拒绝访问。不以尚未应用的密码草稿授予权限。

基本信息包括名称、世界 Id、游戏版本和有时间标记的状态；页面不展示游戏 UDP 端口；设置区展示运行观测的当前值及参数目录默认值，不展示已应用基准，离线或观测失败明确显示未知。不显示待应用草稿、管理接口、密码、宿主目录、容器标识或审计记录。参数采用安全字段白名单。

只读会话仅授权一个实例与世界，30 分钟固定有效期；退出、服务重启、已应用密码变化、世界变化或实例不可用即失效。失败提示统一为世界 Id 或密码不可用，限制密码尝试，不允许枚举实例。访客不能创建备份、保存、恢复、改设置、启停、管理玩家或调用任何管理 API。管理员登录和访客登录独立。

备份只列当前实例同世界恢复点。下载包含该世界目录内的 .sav 文件（世界与玩家数据），不含 Config、日志、安装、运维清单、秘密、环境文件或其他世界；文件含玩家数据，因此页面明确说明下载内容。损坏、跨实例、跨世界、符号链接、活动任务或锁冲突拒绝导出。没有备份提供空状态，不自动创建。ZIP 是已有离线快照，下载不停止游戏，也不代表真实角色恢复已验收。

## 验收

正确密码可访问；错误、空密码、未知/歧义世界统一拒绝；密码草稿不改变访客认证；应用新密码撤销旧会话。深链接、刷新、退出、过期和重新输入完整可用；切换世界不显示旧详情。后端阻止跨世界及所有管理访问；设置和日志不泄漏秘密；ZIP 内容、校验、归属、互斥和临时文件清理有回归。遵循本项目 UI，窄屏、键盘及错误/加载/空状态可用。
