# 流水线、发行与官网需求

版本日期：2026-10-06。状态：已采纳。替代原版交付需求；本次仅调整流程，暂不发行版本。

## REQ-16 日常校验与版本发行

日常 main 推送、PR 和手动运行 CI：校验文档、版本契约、前端和 Linux/Windows 后端，运行 Docker 单元测试并构建应用镜像；不创建正式 Release 或安装包。

只有推送 vX.Y.Z 或 vX.Y.Z-rc.N 形式的合法 tag 才正式发行。tag 必须匹配 version.json，且有且仅有一份非空的带日期版本说明。先复用完整 CI，再生成 Linux x64 Docker 镜像归档、Windows x64 自包含程序 ZIP、Inno 安装包。三个文件齐全后提供 SHA256SUMS，用仓库版本说明作为 Release 正文；带后缀标记为 prerelease，重跑同一 tag 更新说明和资产。临时构建产物保留 7 天，Release 资产长期保留并要求仓库访问权限。

提供仅打包演练入口，不创建 tag、Release，不部署服务。测试和构建通过不能替代真实玩家、目标机安装或生产验收。

## REQ-17 版本化项目介绍与官网

README 面向使用者，包含主要能力、平台与权限边界、快速开始、目录、第三方组件和文档链接，不以开发过程记录充当项目介绍。

官网保留蓝白静态页面、桌面与手机布局，支持中英双语：首页、功能说明、使用指南和发布日志的列表与详情提供对应语言内容；主导航提供语言切换，切换后仍停留在对应文档或版本，不返回首页。中文原地址继续有效，英文有独立地址，可直接分享。此要求限官网，不改变管理控制台语言。

下载入口指向 GitHub Releases。仅 v* tag 部署 Pages，使用相同 tag 的源码、版本和说明；普通提交不更新公开网站。Pages 与发行独立运行，分别检查结果。源码保持私有，官网公开，内部文档和运行数据不进入站点。
