# 控制台 URL 路由需求

日期：2026-10-07（北京时间）。状态：实现及隔离验收通过。补充现行 MVP 的 REQ-18，不替代已有实例安全、权限或维护要求。

## REQ-18 页面地址与导航

- 仪表盘、登录、首次设置、实例列表、实例详情的各页签及主机与安全具有独立 URL；复制地址、直接访问和刷新恢复对应页面。
- 普通站内导航支持浏览器前进、后退；主导航、实例入口及返回列表为真实链接，支持新标签页。
- 已有管理账号时，未登录访问管理地址先登录，成功后返回原页面；退出及会话失效后不能通过历史记录看到管理页面。
- 未初始化时统一进入首次设置；初始化完成后进入登录。根地址兼容现有入口，根据会话选择实例列表或只读仪表盘。
- 未知地址、不存在或已取消接管的实例显示明确提示及返回入口，不能冒充实例列表。
- 页面标题随实例及页签更新；导航后清理旧页面弹窗、日志、恢复点及搜索状态，取消旧页面读取，继续遵守后台任务互斥。
- 密码、一次性预检、确认令牌及写操作不进入 URL；地址访问不能执行实例命令。登录回跳只能访问已知本地页面。
