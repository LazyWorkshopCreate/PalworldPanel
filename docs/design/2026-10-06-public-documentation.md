# 公开文档与发布日志设计

日期：2026-10-06。状态：已实现。关联 REQ-17 / W19，是现行交付与官网设计的补充。

官网首页负责介绍和入口；用户文档与发布日志采用独立列表、详情。公开用户文档不直接发布内部需求、环境快照或运维证据。

| 页面 | 路径 | 内容 |
|---|---|---|
| 文档列表 | website/docs/index.html | 功能说明、使用指南，类别与摘要 |
| 功能说明 | website/docs/features.html | 实例、监控、参数草稿、备份恢复、权限与支持边界 |
| 使用指南 | website/docs/guide.html | 环境、安装、首次访问、创建、设置、日志、备份、升级步骤 |
| 发布日志列表 | website/releases/index.html | 日期与版本，进入版本详情 |
| 版本详情 | website/releases/vVERSION.html | 对应版本说明、下载升级、验证范围与发行状态 |

详情页包含面包屑和返回列表，用户文档含本页目录。桌面目录靠左，手机放在正文上方。导航、图片和站内链接使用相对路径，支持 GitHub Pages 的项目路径前缀；沿用隐藏滚动条与正常滚动。

scripts/Build-Website.mjs 负责确定性生成首页及五类文档/日志页面。中英内容来源、语言地址及英文发行说明维护见[双语设计](2026-10-06-website-languages.md)。版本详情从对应语言的 Markdown 源生成，不在 HTML 中维护第二份版本正文。版本说明支持标题、段落、无序列表、行内代码与加粗；暂不支持的 Markdown 块会显式拒绝，避免错误渲染。版本号沿用发行版本验证，重复版本拒绝生成。

页面提交到仓库，修改内容后运行 node scripts/Build-Website.mjs。CI 和 Pages 执行 --check，拒绝源内容与生成页面不一致；Test-Website 按生成清单核验具名页面、截图、跨页面链接与锚点，拒绝未知文件及链接文件。仅部署 website，生成器不复制内部 docs。

新增版本说明后生成列表和对应详情。发行说明已准备不等于正式 Release 已发布，正文保留真实状态，下载入口指向 GitHub Releases。Pages 仍仅由 v* tag 触发，本次不创建 tag 或 Release。
