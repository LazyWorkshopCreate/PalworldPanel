# 官网中英双语设计

版本日期：2026-10-06。状态：已实现。适用范围：REQ-17 / W21 官网公开页面。替代来源：无，补充[公开文档设计](2026-10-06-public-documentation.md)。

## 地址与切换

中文保留根路径，英文位于 `en/`，两种语言有相同的文档 slug 和版本详情。每页主导航的 English / 中文链接指向对应页；普通站内导航保留当前语言。采用可直接访问的静态地址，不依赖脚本、浏览器语言或存储。HTML 声明语言，并提供 zh-CN、en 和默认中文的 hreflang 对应关系。所有站内链接使用相对路径，兼容 GitHub Pages 项目子路径。

所有页面前三项导航统一为首页 / 文档 / 发布日志（Home / Documentation / Release notes），首页功能仍由正文“了解功能”入口访问。三项共享字号、内边距、圆角、悬停与选中样式，当前所属栏目使用 `aria-current="page"` 和浅蓝底色。窄屏允许导航整体换行，保持文字完整。

## 内容维护

中英首页源模板在 `scripts/website-templates/`；中文用户文档源在生成器，英文源在 `scripts/website-english.mjs`。通用界面文本集中维护翻译字典，生成器对英文页使用对应文本。修改内容后运行 `node scripts/Build-Website.mjs`，提交源与生成页；不直接修改 `website/` 中生成的 HTML。

版本日志中文源位于 `docs/releases/`，英文源位于 `docs/releases/en/`，名称一致。新版本缺少英文说明时构建失败，不静默显示中文。两种说明均描述相同版本和验证边界；GitHub Release 正文仍使用中文源。英文指南保留控制台中文按钮对照，明确管理控制台当前使用中文。

功能说明截图与中英文图注由 `scripts/website-screenshots.mjs` 维护，按章节插入；两种语言共享审核后的图片。图片可点击查看原图，正文中提供采集日期及脱敏说明，不能包含密码或未审核运行资料。首页保持不展示实拍模块。

## 校验与发布

`Test-Website.mjs` 校验对应页、语言声明、hreflang、切换目标、相对资源及锚点，递归限制英文目录公开文件，禁止内部资料和符号链接进入站点。原有 CI 与 Pages 流程复用此检查。继续隐藏滚动条，保留正常滚动和键盘导航；已移除的控制台实拍模块不恢复。
