# 实例更新设计

日期：2026-10-07（北京时间）。状态：已实现。对应 [REQ-19](../requirements/2026-10-07-instance-updates.md)。

## 检查及版本来源

认证及 CSRF 保护的 POST `/api/v1/instances/{id}/update-check` 在实例身份锁内检查权限、未结束任务、配置源及安装记录。
读取对应实例 `steamapps/appmanifest_2394010.acf`，核对 app、完整安装状态、正式 Linux depot 2394012、内容 manifest。批准镜像使用的 DepotDownloader 会写旧 buildid，因此是否更新以内容 manifest 比较为准。

使用固定 HTTPS `api.steamcmd.net/v1/info/2394010` 的正式分支元数据。它是第三方 Steam 元数据镜像，也是批准游戏镜像使用的来源，不是官方 Steam API。固定目标、禁重定向、15 秒超时和 1 MiB 响应限制；失败不能解释为最新。
通过官方 Steam 新闻 API（游戏 app 1623730）的社区公告标题获取版本号，仅接受与正式分支发布时间相差 6 小时以内的版本公告。发现内容更新却无法确认版本号时拒绝升级并提示重查。

响应包含 up-to-date / available、当前及目标版本、检查时间；仅 available 含十分钟有效的加密检查凭据。凭据绑定实例 ID、修订、配置源、固定镜像、当前/目标 manifest、目标 build 和已核实版本。凭据不进入 URL、日志或确认弹窗正文。预览、提交、执行器分别复核目标与当前安装；旧手动升级 API 请求拒绝。

## 执行及恢复

保持已批准固定镜像，通过独立更新任务下载正式 Linux 游戏内容，不在 UI 提供镜像更换或任意版本选择。固定版本或测试分支实例拒绝自动升级。
取得实例互斥及重 IO 锁，检查空间、保存进度并停服，建立包含旧安装、旧配置及旧 Saved 的完整恢复点。
使用同一固定镜像的安装适配器，临时容器仅挂载该实例 data；固定脚本开启错误退出，显式通过 DepotDownloader 验证正式分支内容，禁用测试版本。任务结束、超时、执行器中断后启动恢复及手动回退前均确认对应更新容器退出，避免后台写入与恢复并发。
核验目标内容 manifest，再以启动更新关闭的配置创建游戏容器；核对游戏 REST 版本、世界、规则及资源。公告版本 v1.0.5 可匹配实际 v1.0.5.102999，不能匹配 v1.0.50。原先停止的实例验证后再次停止。

自动检查通过后进入等待玩家确认状态；失败保留恢复锁和配套恢复点，不能自动重试或自动接受。完整回退保留失败现场并保持实例停止。升级不会证明跨版本玩家角色兼容，仍需实际客户端验证。

## 界面

打开即显示检查中，关闭取消读取。检查失败显示错误与重新检查；无更新显示当前版本及无需更新；有更新以并排版本卡展示当前和目标版本，窄屏自动堆叠。继续升级进入已有操作确认，保留任务期间禁用和互斥规则。
