# PalworldPanel 前端 UI 设计规范

版本日期：2026-10-05。修订日期：2026-10-06。状态：已采纳，本机界面已实现；验收证据见导航选定的验证记录。适用范围：登录、实例、设置、日志、备份恢复、任务与主机安全页面。替代来源：无。本文是本项目的视觉与交互契约，页面业务流程见[系统设计 §5](2026-10-06-system-design-r4.md#5-页面结构与线框req-01070912)。

## 风格与布局

采用明亮、紧凑但有留白的管理控制台：浅灰画布、白色卡片、蓝色主要动作、细边框和轻阴影。装饰不抢占实例、状态、任务和风险信息；MVP 使用浅色主题，不另建深色主题。产品名称统一 PalworldPanel，中文页面标题与业务文案，不沿用其他产品的名称、图形或页面术语。

桌面顶部 sticky 导航高 72px，包含产品标识、实例/主机与安全入口、更新时间和管理员操作；正文居中最大宽 1440px，桌面横向留白 32px、顶部 42px。页面顺序为标题与摘要/主操作 → 主机或实例指标 → 筛选 → 卡片或表格 → 任务与异常说明。实例详情采用页内 tabs，任务列表并入实例详情，按实例过滤，不设置全局任务主菜单；不增加多层侧栏。

指标卡桌面通常四列，按页面信息量调整；卡片间距 16px，内边距 24px。实例列表用白色卡片组织标题、接管模式、状态和操作，数据区用表格；任务与备份用表格突出阶段、时间、一致性和结果。复杂页面不能为了四列放入无意义统计。

## 组件与状态

产品页面不展示开发环境差异、生产验收边界、实现组件或泛化安全声明。外部容器限额不完整的说明不作为常驻横幅；容量校验仍由后端执行，实际不足时使用可操作的简短提示。主机指标、未知值、请求错误和操作影响仍保留；技术解释及验证边界放入仓库文档。

主要动作使用蓝底白字按钮，每个区域只突出当前关键动作；次要动作白底细边框。清理、回退等危险动作使用明确危险文案和红色语义，不能把日常停止与永久删除混成同级主按钮。禁用态说明原因，不能只靠半透明表现。

实例详情操作栏保持一行，常驻启动、停止、离线备份与“更多”。重启、保存、强制停止、升级、受控接管、规则克隆及移除/隔离/清空等放入折叠面板，沿用权限禁用及后端确认流程。更多面板支持 Tab、Esc 与点击外部关闭；选择后折叠，后续确认弹窗返回焦点至可见的“更多”按钮。

实例详情概览仅展示世界 GUID、游戏版本、管理模式、运行/接口状态、玩家/FPS、天数/据点、本地 UDP 端口、CPU/内存用量及采样时间/状态。详情不展示主机级汇总指标、外部容器说明、套接字诊断段落和重复验收提示；未知及过期状态仍如实显示，实际错误和超预算告警保留。

备份与恢复页分为独立的“定时备份”和“手动恢复”卡片。定时策略的时间、保留天数与保存按钮按底边对齐；手动区域先展示恢复点列表及立即离线备份，再以分隔线划分 ZIP 导入。恢复点操作按钮统一留间距，上传预检的世界选择与执行按钮对齐，信息文字独占一行；窄屏表单纵向排列，列表在自身容器滚动。

表格列标题使用次级颜色，细分隔线，操作列集中在末尾；GUID/长路径可截断并提供完整可读信息或复制，但密码永不提供读取/复制。地址必须标 UDP 与证据时间。复制成功给短反馈，错误持续显示可操作原因。

状态用文字、图标与颜色共同表达。运行/停止是容器状态，API 健康是接口状态，监听/LAN 已验证是游戏连接证据；任务执行中、失败、需要处理独立显示。没有数据用“未获取/未验证”，不能填 0 或绿色健康。过期数据保留最后采样值与时间并标“已过期”，停止流式更新不能伪装实时。

表单标签常驻，单位与范围可见；字段错误紧邻字段。设置采用参数列表，分别显示当前值、项目默认值和草稿值；每行“修改”打开单参数弹窗，提供保存到草稿、取消和使用默认值（名称无固定默认）。当前值来自运行观测或已应用配置，无法核实时显示未知；项目默认值不是官方游戏默认或已生效值。取消/Esc 不改变草稿，关闭返回触发按钮；保存草稿后通过独立应用流程生效。密码为只写字段，列表不回显，修改在专用弹窗内进行。窄屏表格在自身容器内横向滚动，不使整个页面溢出。应用前展示实例、变更和重启影响；提交后展示任务链接而非等待整个 HTTP 请求完成。上传预检和执行是不同动作，不把选择文件当成已授权停服。

Radix Dialog 用于确认与必要模态流程：标题、影响、当前实例/世界、恢复点和可选动作齐全；危险确认绑定后端预览，不能仅写“确定吗”。初始焦点落在安全位置，提供取消，关闭后回到触发控件。交互必须由后端权限与任务约束再次验证。

## 响应式与可访问性

1100px 以下指标改两列，卡片操作可换行；650px 以下正文横向留白 16–18px，标题 26px，表单单列，筛选与按钮换行；窄屏指标可进一步单列。宽表格在独立区域横向滚动，不让整页横向溢出。模态框限制视口宽高并可滚动，不能挡住确认/取消。

支持键盘导航、可见 focus ring、语义标题/表格、输入标签和对话框标题说明；图标按钮有可读名称，装饰图标从辅助技术隐藏。状态变化适度通知，SSE 日志不逐行朗读。普通正文目标对比度至少 4.5:1，大字与必要控件边界目标至少 3:1；颜色初值不替代实际验证。保留字体放大、减少动态效果和移动触控空间，禁止全局移除 outline 而不给替代焦点。

## 验收

W04/W05/W08/W10 验收页面结构、token 一致性、键盘/焦点、390/768/1440px 布局、200% 放大、长实例名、空数据、过期数据、错误、忙碌与危险确认。交互测试使用 Testing Library，界面实现后再提供截图证据；当前只完成规范，未进行视觉或浏览器验证。

2026-10-06 实际对比度复核：辅助正文在浅灰画布约 4.75:1，控件边界采用 #8794a7 对白底约 3.08:1；装饰性卡片边框仍为浅色。键盘焦点轮廓保持主要蓝色，危险对话框关闭恢复触发按钮。

## 完整参数列表补充（2026-10-06）

设置页显示共用目录中的全部游戏参数，另外显示 CPU/内存。参数单元格以中文名为主，原始字段等宽显示；搜索按中文名或字段匹配，忽略字段大小写，空结果清晰提示。当前值来自文件配置/运行观测，默认值标注配置基线，未知默认显示未知；文本、数值、布尔、枚举、列表分别编辑，保持弹窗取消、焦点返回与保存草稿流程。密码行保留原字段且仅可修改；面板托管参数显示“面板管理”，不提供独立编辑。

主机页分为独立的监控指标、备份与灾备、操作记录卡片。CPU 使用率、已用内存、可用内存并列展示，采样时间放在指标区标题旁；窄屏指标堆叠，标题与操作按钮可换行。恢复点与灾备导出只在备份区，审计表格在操作记录区直接显示，不混入恢复点列表。无记录提供空状态。

未登录仪表盘与右侧导航（2026-10-06）：品牌左对齐，主菜单推至右侧，登录/退出位于最右；窄屏菜单换行后仍靠右。白名单访客默认看到实例与主机只读指标，未登录不显示管理按钮/设置/日志/备份；右侧登录打开弹窗，取消/Esc 返回登录按钮焦点，成功进入管理视图，退出回到仪表盘。未知不显示零，读取失败明确过期。

正文滚动调整（2026-10-06）：全页面 shell 占据动态视口，顶部标题/导航栏独立于滚动区并按窄屏换行自然计算高度；正文和页脚在下方的 page-scroll 区域滚动，滚动条从标题栏下方开始。已登录和未登录仪表盘共用该布局，正文滚动区可键盘聚焦，弹窗仍使用独立 portal/滚动。

正文滚动条隐藏（2026-10-06）：page-scroll 不显示滚动条或预留轨道，保留 overflow:auto、滚轮、触控和聚焦后的键盘滚动；已登录和只读仪表盘共用。

设置页分区间距（2026-10-06）：参数表后访问密码标题留 32px 顶部间距、12px 底部间距；密码表后的保存草稿/应用按钮组留 24px 顶部间距，避免紧贴表格边线。

创建新世界弹窗分组（2026-10-06）：基本信息（实例名称/玩家上限）、资源配置（CPU/内存）、游戏规则（死亡掉落/离线惩罚/建筑倍率）使用 fieldset/legend 独立分组，两列对齐、窄屏一列。底部操作与表单用分隔线和留白区分并右对齐；预检结果分基本信息与资源、目录与端口两组，原先预检后确认的提交契约保留。

2026-10-06 初始化进度补充：实例列表卡片与详情页标签上方显示状态、当前阶段、阶段计数、进度条与步骤列表；安装等待不显示未经观测的百分比，失败用明显边框和处理文案。状态区使用 aria-live 与有名称的 progress，窄屏步骤自动换行。日志最新记录置顶，每 5 秒自动刷新。

2026-10-06 标注兼容补充：本机回环预览支持内置浏览器动态注入的标注光标与选择样式；不在业务 CSS 强制覆盖浏览器的标注光标。样式注入兼容范围以 Windows 部署设计为准，实际光标/点击反馈需在内置浏览器验收。

2026-10-06 密码编辑补充（REQ-05 / W05）：修改管理/游戏密码使用单列输入区，工具行提供随机生成和显示/隐藏密码；显式清除游戏密码独立显示为正常尺寸复选项，底部取消和保存到草稿右对齐。随机值由浏览器密码学随机源生成 24 位，生成后可继续编辑；已有密码不读取、不回显。管理密码须 16–128 字符，游戏密码最多 128 字符，空输入不提交变更；清除须显式选择。提交失败保留输入并就近显示错误，关闭清空；草稿仍需独立应用重启生效。

密码近期认证补充（2026-10-06）：后端返回 ReauthenticationRequired 时保留输入，在同一弹窗提供面板管理员登录密码验证区与验证并保存草稿按钮；验证失败不提交密码变更，登录密码使用后清空。验证成功更新会话和 CSRF 后重试保存，后端 5 分钟近期认证规则保持。

2026-10-06 设置草稿展示简化（REQ-05 / W05）：移除比较期望、已应用与实际规则折叠区域及重复汇总状态，使用参数列表草稿值单元格浅琥珀色高亮和待应用标记。高亮以已应用配置为基准，数值等价不误报，应用后恢复普通样式；实际观测差异不等于草稿未应用，未知基准不伪造差异。

2026-10-06 实例操作确认补充（REQ-03/REQ-04 / W05）：操作栏和更多内全部功能先显示弹窗，不以预检请求成功作为打开弹窗的条件。弹窗说明实例和该操作影响，预检中禁用执行、允许取消；错误和近期身份验证在弹窗内完成。预检成功后仅显式确认可提交，取消/Esc/关闭不创建任务，清理继续要求完整实例名。仅克隆规则先确认不复制存档和密码，再进入新实例配置；升级先配置升级范围，再进入统一确认。

2026-10-06 访问密码状态列补充（REQ-05 / W05）：管理/游戏密码列表与常规参数对齐，包含当前值、默认值、草稿值和操作。当前值仅显示已设置/未设置/未知，默认值说明新实例随机生成；草稿值只显示已修改/未修改/未知，修改未应用时高亮并标待应用。密码、密文、哈希和长度不提供给浏览器；后端比较已应用与草稿的语义值，相同密码即使重新加密也不标修改。保存草稿后刷新状态，应用后消除高亮。

2026-10-06 实例列表简化（REQ-04 / W05）：删除没有检测数据的固定连接证据/未验证占位。卡片摘要保留游戏 UDP 端口、版本和资源配额，宽屏三列；不把运行/API 健康推断为玩家可连接。

2026-10-06 弹窗布局统一（REQ-04/REQ-05/REQ-09 / W05）：共享 Modal 划分标题、说明、可滚动内容区，标题关闭按钮顶部对齐，说明与表单保持留白；字段纵向排列并留 20px 间距，底部操作用分隔线与 20px 留白，靠右排列并可换行。所有弹窗复选框使用固定 18px 尺寸和横向标签，长任务标识与说明自动换行，任务恢复信息以两列键值排列、窄屏单列。覆盖导出、参数、升级、接管、恢复、创建、密码及动作确认；加密导出说明独立口令 16–128 字符，并在弹窗内显示失败原因。

2026-10-06 配置应用锁定（REQ-05 / W05）：应用并重启在确认、提交和后台排队/执行期间禁用，显示等待确认或应用中；NeedsAttention 显示应用需处理并保持锁定，提供查看任务入口。确认取消释放确认态；接口接受不等于完成，成功完成才恢复正常。明确 Failed/Cancelled/RolledBack 终态后允许用户重新发起，仍执行二次确认，不自动重试。刷新/重新登录从持久任务恢复未结束锁定；暂未获取到已接受任务时保留本地待确认任务标识。

2026-10-06 实例卡片游戏地址（REQ-04 / W05）：游戏端口改为游戏地址，显示 Docker 映射 IP:端口 / UDP；IPv6 地址使用方括号。仅监听地址不代表连接验收，映射缺失显示地址未知且保留已知端口，不从面板访问 URL 猜测游戏地址。
