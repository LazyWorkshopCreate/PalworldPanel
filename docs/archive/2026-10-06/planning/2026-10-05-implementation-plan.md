| 场景 | 必须观察的结果 |
|---|---|
| 接管目录相同、嵌套或 symlink | 拒绝写管理，两个实例都不改 |
| 同实例同时升级/导入/备份 | 返回冲突/队列，不并行修改；不同实例轻操作仍可执行 |
| 同 key 重复点击和断网刷新 | 原任务号；payload 改变返回冲突 |
| ZIP 绝对路径、反斜线穿越、重复/大小写碰撞、zip bomb、加密包 | 展开受限，不越界，运行目录 hash 不变 |
| 多 GUID、来源含密码 Config、_dps.sav 等附件 | 明确选世界、忽略源秘密配置、附件兼容规则可解释 |
| Save timeout、Docker stop timeout、SteamCMD 失败 | 结果未知/失败阶段准确，不虚报成功，不自动重跑破坏操作 |
| 恢复点未完成、磁盘满、chmod/rename 失败 | 不换 Saved 或保持停服，原恢复点可用 |
| 每个 rename 和状态提交后进程/主机中断 | 按 journal 恢复，不自动创建空世界；restart hold 生效 |
| REST 401、404/字段缺失、游戏 API 正常但 UDP 丢包 | 状态分层；401 不归类网络 UDP 故障；缺指标为 unknown |
| 启动后 GUID 正确但原账号提示新建角色 | 标玩家未恢复，停止继续写档，提供回退 |
| 手工 Compose 改动或外部 cron | SourceDrift/单写入者不满足，暂停写操作 |
| 日志/REST 返回密码、Authorization、ANSI/HTML 恶意字符 | 秘密隐藏、控制符编码、XSS 不执行 |
| 管理网络扫描与 IP 绕过 | root/Docker 权限符合决策；REST/RCON/Docker 无公网发布；面板只监听指定 LAN；白名单外内网/公网、伪造转发头、mapped IPv6、回环、代理绕过全部拒绝；允许 IP 登录可用，空/无效配置不开放 |
| 普通备份恢复、游戏升级失败、面板 DB schema 回退 | 分别按存档/配套安装/DB 备份恢复，不能只换镜像 |

文件事务、ZIP 安全和跨实例隔离需有针对性自动化测试；真实玩家恢复需 LAN 客户端证据。公网 UDP 和外网验收在面板范围之外，不进入面板工作项。对文档阶段只做链接、覆盖、编号与一致性检查，不运行上述测试。

## 4. 决策和阻塞管理

D1–D7 见[导航](../../../README.md#决策状态)，其余策略已按用户最佳实践授权采纳，详见[运维默认值](../../../design/2026-10-05-operational-defaults.md)；无需再次确认设计方向。实际白名单 IP、内网监听地址与 TLS 参数是未来部署输入，不从快照自动填。遇到不兼容镜像、不可无损编辑、外部写入者不可协调、存档版本未知、权限/空间不足时，降低为只读或停止该变更，保留原实例和回退点，记录 NeedsAttention。技术栈和权限方向确定不代表默认同意生产变更。

完成标准：所有面板范围内需求有证据或明确延期；至少两实例隔离、一次全新世界创建、一次同平台 ZIP 导入及原账号 LAN 入服确认、一次回退、一次升级失败演练和面板恢复演练通过。本机 UDP 映射与监听有证据；公网 UDP 状态不作为面板交付条件，不要求其配置、诊断或验收。
