## 交付和后续准入

当前交付以可构建源码、锁定依赖、Docker 镜像、本机合成实例演练、文档与项目范围清理为准。完整生产准入仍要求 W12–W15 的对应实证，不能因本机交付完成而把旧快照、原角色恢复或生产可用性标为 Passed。

遇到未知模板、资源无法核定、配套版本不匹配、空间不足、外部写入者或配置漂移，保持只读或停止变更。实例回退先保存/停止并保留现场；不自动重试破坏操作。后续实质替代建立新日期版本，保留 REQ/W 身份编号和失败证据。

REQ-06 / W04 / W08 后续补充：121 项游戏参数共用目录、中文名/字段搜索、类型化弹窗、只写秘密和托管参数保护已实现。Windows/Linux 各 59 项及前端 8 项 Passed；独立复制 DB 的 API 场景 Passed，INI 写盘/保留未知字段/秘密不回读有测试证据。未逐项在真实游戏中验证 121 项参数行为；该兼容验证仍需按实际游戏 build 进行，不能扩展已有核心规则真实游戏结果。

W04 / W05 / W09：主机页监控、备份记录、操作记录区域独立，保留原采样、审计及导出行为。验收为前端格式/类型/构建、文档结构和本机新静态资源核验；未新增监控历史持久化。

W04 / W05 / REQ-12：移除全局任务主导航与页面，实例详情任务页签保留按 instanceId 筛选的进度、取消及恢复操作。前端格式/类型/构建、文档和本机最新资源核验完成。
