# PalworldPanel v0.2.0-rc.1

新增通过世界 Id 和游戏连接密码访问的只读详情页，提供游戏设置、基本信息、脱敏日志与世界存档下载。

## 新增与改进

- Pages 增加和朋友共享世界的功能介绍与房主/访客操作指南：朋友无需管理员账号即可随时下载已有世界备份，并明确访问条件、快照时间及普通 ZIP 的范围。

- 世界访客使用独立会话，管理员登录不会跳过访客认证；空游戏密码不开放访问。会话固定过期，世界或已应用密码变化后失效，登录失败限流。
- 基本信息常驻，游戏设置、世界备份和最近日志使用页签，支持深链接、刷新、前进后退及键盘切换。
- 游戏设置支持中文名和字段名搜索，显示运行观测的当前值及共用参数目录默认值，缺少观测时明确显示未知。
- 只下载当前世界已有离线备份中的世界和玩家存档，校验归属、清单与摘要；不导出管理配置、密码或其他世界数据，不提供访客创建或恢复操作。
- 统一管理与访客登录布局，在实例列表及详情增加只读入口。
- 参数弹窗直接持久保存草稿，采用共享范围和选项校验，提示无效值并阻止保存。

## 修复

- 真实游戏设置中的列表数组转换为可读值，清除日志 ANSI 颜色序列并保留脱敏。
- 为显式启用的本机隔离测试浏览器提供精确来源的标注样式兼容，不放宽脚本策略或普通来源访问权限。
- 新建实例的游戏 UDP 绑定所有 IPv4 接口，管理 REST/RCON 仍保持回环；既有实例不会由此次面板程序发行自动重建。

## 升级与兼容性

- 升级前备份面板管理状态、主密钥、部署配置及游戏存档，处理未结束任务，并保留配套旧程序或镜像用于回退。
- Windows 使用“仅升级程序”保留配置与实例数据；Linux 保留原持久挂载。不需要随面板升级游戏版本。
- 只读入口仍受精确来源 IP 白名单约束，游戏密码不会赋予管理员权限，管理接口不公开。

## 验证与限制

- 本机 Release 非 Desktop 后端 231 项、前端 152 项测试通过，构建、格式与文档检查通过。
- 已在本机 Docker 隔离的真实游戏服务端验证设置、日志和世界存档导出；文件摘要及归档检查通过。内置浏览器已验证登录、页签、搜索与默认值展示。
- 未验证真人客户端角色恢复、生产部署或公网游戏连通性。Windows 安装包未签名。
