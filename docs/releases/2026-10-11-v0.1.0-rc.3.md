# PalworldPanel v0.1.0-rc.3

新增世界页的玩家连接控制与存档文件列表，改善后台任务故障隔离、定时备份补试和管理员认证，并修复世界页的实例切换、互斥和采样错误处理。

## 新增与改进

- 世界页显示已知玩家、在线状态、封禁编号和对应存档文件；运行时通过回环游戏接口踢出、封禁和解除封禁，停止时仅修改本实例封禁列表。
- 世界页按实例隔离玩家和弹窗，每轮读取完成五秒后更新状态。读取失败保留过期提示，后续采样成功自动恢复；存档读取失败不遮蔽可用的玩家列表。
- 单条任务的无效载荷与执行异常落入失败或待处理状态并写脱敏诊断，不让该任务异常终止执行器。
- 定时备份仅在同一天的预检阶段失败时有限补试，最多三次；成功或已进入其他阶段时不再补跑。
- 修改备份策略要求近期管理员认证，过期时保留输入并在重新登录后提交。操作错误与采样错误分别展示。

## 修复

- 连接控制持有与其他实例写操作共用的 OS 锁，锁内核实实例与未结束任务，防止并发修改封禁列表或与恢复、启动等操作交错。
- 切换实例清除旧玩家、确认弹窗与密码，取消旧请求并忽略迟到响应，防止把旧玩家操作提交给新实例。
- 游戏接口连接拒绝或超时降级为历史玩家及封禁列表；请求取消继续传播。
- 玩家列表仅枚举玩家存档文件名，不解压存档正文，损坏的存档容器不会阻止玩家投影。
- 减少活动任务查询与近期采样中的重复 Docker 地址查询。

## 升级与兼容性

- 升级前备份面板管理状态、主密钥、部署配置和游戏存档，处理未结束任务，并保留旧程序或镜像及其配套管理状态作为回退点。
- Windows 使用“仅升级程序”保留账号、配置与实例数据；Linux 更新面板镜像并保留原持久化挂载。无需随面板升级游戏版本。
- 玩家历史表在打开管理数据库时建立，按实例记录面板见过的玩家。回退时使用配套旧管理状态，不承诺旧程序对新增表的完整兼容。
- 本版不提供存档数值编辑或玩家存档隔离；控制台仍为中文，管理接口仍受内网白名单、会话及 CSRF 保护。

## 验证与限制

- Windows 本机 Release 后端 187 项、前端 107 项测试通过，完成 Prettier、TypeScript/Vite 构建、文档和差异空白检查。
- 回归覆盖实例锁冲突、活动恢复任务、实例切换、迟到响应、独立读取、自动采样恢复、游戏接口异常降级和请求取消。
- Linux/Windows 云端 CI、Docker 构建、安装包及资产校验由发行流水线执行；本说明不提前宣称尚未完成的云端结果。
- 世界页的真实游戏踢出、封禁和解除接口、真实玩家登录与角色恢复尚未演练；自动化检查不替代生产或玩家验收。
- Windows 安装包未签名；公网 UDP 转发、监控和诊断不属于面板范围。
