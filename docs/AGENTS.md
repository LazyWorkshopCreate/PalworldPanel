# 文档协作补充

继承根目录 AGENTS.md。先读 [导航](README.md)和[文档维护规则](standards/documentation-policy.md)，按[目录规划](standards/repository-layout.md)放置内容。

- 不把业务需求写成实现步骤，不把设计采纳或文档 Passed 写成工程已运行。
- 不重写原始环境快照的历史事实，实时只读结果另写日期记录。
- 迁移使用一份现行正文，修复链接、导航和任务书范围说明；不保留多个同名方案造成歧义。
- ADR 实质替代新增编号；REQ-01–15、W01–17 保持现有编号并继续追踪。
- 时效文档使用年月日前缀；实质替代时移动旧版到 archive，登记归档台账和新旧链接。归档不继续更新业务结论；现行契约不得依赖归档中的过期约束。
- 工程策略默认值只维护在 design/2026-10-05-operational-defaults.md；游戏参数的批准镜像基线在共用 game-settings.json 维护，未知官方默认不猜测。其他文档按需摘要并引用。
- 完成后从仓库根运行文档检查；脚本不验证外部链接、锚点、设计正确性或工程能力，这些边界须如实注明。
