## 本机差异及失败修复

- 首轮 Linux SQLite 加载失败：系统只有 `libsqlite3.so.0`，显式动态解析后重跑通过。SDK 下载中断，重试完成。
- 首次新建绑定 Linux VM 网桥失败并 NeedsAttention。DesktopValidation 仅测试发布至 Windows 回环、缩小预算；生产仍要求 LAN 地址、16 GiB 实例预算及 4 GiB 预留。
- 引号密码曾引发实际 REST 401，失败回退保留原世界；补齐 INI 转义/raw env 后真实重跑通过。
- 启动观测过早、克隆 GUID 早于首个 Saved 写盘：失效采样缓存、等待 info/settings/metrics，实际 save 确认文件生成后通过。
- 中断测试错误要求临时容器存在、hash 断言忽略十六进制大小写、日志断言未等待落地：修正观测与有界等待后通过，保留失败经历。
- 对话框动态 style 被 CSP 拒绝、异步预览关闭时焦点丢失：每响应 nonce 和组件注入支持、提前保存触发元素；最终对话框及新建预检复测通过。

浏览器通过专用 TCP 桥接访问 Windows 回环 HTTPS，源为白名单 .5。页面证据与原浏览器来源 ACL 分开；ACL 来自 .10/.11 独立客户端。自签信任跳过只用于夹具，桥接/测试预算不作为生产配置。
