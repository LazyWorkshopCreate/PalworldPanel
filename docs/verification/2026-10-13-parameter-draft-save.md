# 参数弹窗草稿持久保存修复

日期：2026-10-13。状态：仓库实现与本机构建 Passed；后续合并部署与接口复核 Passed，现场浏览器交互未验证。关联：REQ-06 / W04 / W08。适用范围：参数列表编辑弹窗，不触发游戏配置应用。替代来源：无。

## 问题与修复

“保存到草稿”原先仅调用前端 setDraft，关闭弹窗后仍须列表“保存草稿”发出 PATCH，按钮承诺与实际行为不一致。

弹窗现在等待当前实例草稿 PATCH 成功后关闭，使用服务器返回的草稿和新修订；列表移除重复保存按钮，保存与应用仍分开。请求失败保留输入并显示错误；保存期间禁止输入、关闭和重复提交。新修订同步服务器草稿，晚返回结果按原实例更新，不覆盖另一实例页面的编辑值。
