## 修改

用户反馈登录视觉与管理登录不一致、内置浏览器 annotate 无法显示。只读入口原来沿用详情的顶部导航和左侧卡片，现与管理登录提取共享 LoginLayout，统一居中卡片、图标、标题字号、表单间距、按钮、卡片内错误和底部返回入口；嵌入式管理员登录仍保留原有无边框样式。只读认证仍只发送世界 Id 与游戏密码，不调用管理员登录。

代码核查发现，现有 CSP 对无 nonce 标注样式的兼容仅覆盖 Windows 127.0.0.1；当前预览实际在 Linux Docker 中运行，浏览器来源为专用测试桥接 172.30.88.5。因此为显式 DesktopValidation 且真实来源精确为该地址的请求补齐 style-src-elem 兼容。不扩大 IP 白名单、不采用转发头、不开放内联脚本或 eval；普通 Linux/LAN 来源仍使用原 nonce 限制。这是基于策略差异的原因判断，当前工具未捕获用户 annotate 操作产生的错误。
