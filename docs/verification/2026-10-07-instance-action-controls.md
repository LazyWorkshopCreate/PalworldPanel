# 实例操作栏状态与互斥验收

日期：2026-10-07。状态：实现及隔离验证通过。范围：REQ-04、REQ-05、W05；实例主操作栏及“更多”菜单。此次为未发行的工作区改动，不代表已安装服务或公开 rc.1 发生更新。

## 操作用途与可用条件

| 操作 | 用途 | 状态条件 |
|---|---|---|
| 启动 | 启动并核实世界及接口 | 可写，实际容器停止或不存在；运行时停用 |
| 停止 | 保存后正常停服，保存失败保持运行 | 可写、实际运行、游戏接口健康 |
| 强制停止 | 跳过保存立即停服 | 可写、容器实际运行/暂停/重启中；不要求游戏接口健康 |
| 重启 | 保存后停服并重新启动 | 可写、实际运行、游戏接口健康；停止时使用启动 |
| 保存 | 保存当前进度，不停服、不生成备份 | 可写、实际运行、游戏接口健康 |
| 离线备份 | 停服备份，原本运行则重新启动，原本停止则保持停止 | 可写，实际运行或停止；运行时须能安全保存 |
| 升级 | 备份安装与存档后升级，进入受控验证及回退流程 | 可写，运行或停止；没有未应用参数或密码草稿；运行时须能安全保存 |
| 仅克隆规则 | 复制面板规则创建独立世界，不复制存档、密码或端口 | 配置已知，未隔离、未永久清空；只读实例亦可克隆；源实例任务未结束时锁定 |
| 移除容器保留数据 | 保存、停服、备份并移除容器，保留实例数据 | 可写、容器存在且运行或停止；容器不存在时停用；运行时须能安全保存 |
| 隔离清理 | 备份、停服、移除容器并隔离目录 | 仅面板创建的可写实例；未隔离、未清空；运行时须能安全保存 |
| 取消接管 | 移除面板登记，保留容器、数据和备份，不改变运行状态 | 无未结束任务；隔离中的实例必须先撤销隔离或完成永久清空 |
| 启用受控写管理 | 确认外部调度停用后受控接管配置和维护 | 已知配置的只读实例，未隔离、未清空，实际状态已核实 |
| 撤销隔离清理 | 恢复目录和写管理，不自动启动 | 面板创建、已隔离且未永久清空 |
| 保留期后永久清空 | 删除隔离目录，保留独立最终备份 | 面板创建、隔离至少 7 天、尚未清空；执行时独立校验最终备份 |

每个按钮通过 title 说明用途；停用时同时解释原因。条件来源是实际容器及接口采样，不以期望运行状态代替实际状态。未知或过期采样禁用依赖运行状态的操作，配置源漂移仍由后端原有校验拒绝。

## 锁定契约及修复

- 前后端共同读取 `src/PalworldPanel.Contracts/instance-actions.json` 的名称、说明、容器状态、权限及健康条件，Docker 前端和后端构建均包含该契约。
- 请求/确认期间锁定操作栏；收到任务回执即记录本地锁，任务列表刷新暂时缺少该任务时也保持锁定，避免可重复点击窗口。
- Queued、Running、NeedsAttention 均保持实例锁；Succeeded、Failed、Cancelled、RolledBack 释放任务锁，并继续按实际状态判断按钮。NeedsAttention 通过任务页处理，不开放新的操作栏命令。
- 设置、日志、备份及任务页也持续采样运行状态；切换实例时不使用另一实例的旧采样，采样失败标记过期。
- API 预览和正式提交独立验证任务及实际运行条件；正式提交保留 revision、单次确认和幂等键校验。执行器在副作用前再次检查条件，并排除正在执行的自身任务。
- SQLite 活跃任务唯一索引及稳定实例文件锁继续提供后端互斥。克隆预检和提交核对源实例锁及任务，阻止从正在变更或待处理的源实例制作新快照。

## 验证证据

- Windows 后端：120 项通过；Docker Linux 后端：120 项通过；前端：73 项通过，包含 14 类操作的锁定、运行/停止/未知、只读、隔离期限、草稿和缺失容器条件。
- 前端回归覆盖：双击确认仅提交一次；收到回执后，即使任务列表暂时落后仍锁定启动、备份、克隆和取消接管；终态后释放。
- Windows 原生隔离面板与实际 Docker Desktop：停止或缺失容器时，不适用操作的预览和提交返回 409 ActionUnavailable，不产生新任务；启动、备份、取消接管可预览。
- 独立合成数据库注入 NeedsAttention：各类 API 预览和提交返回 409 TaskConflict；Playwright 实际网页操作栏及“更多”全部锁定；结束合成任务后启动恢复可用，停止仍不可用。
- 实际浏览器逐按钮检查用途 title、启动/停止/保存状态、既有实例隔离清理停用，以及缺失容器时移除按钮停用；截图在被忽略的 output/playwright 中。
- Windows 原生发布构建及 Linux 应用镜像构建通过。此轮没有启停真实游戏、安装更新原服务、修改 tag 或发布新资产。

运行状态、权限、保留期等矩阵在策略测试中覆盖；此轮实际 API/浏览器主要验证停止/缺失容器及任务锁。运行中、升级/恢复等完整生命周期的实际游戏证据见 [生命周期验收](2026-10-07-lifecycle-acceptance.md)，不能把本轮按钮验收当作新的完整游戏或玩家恢复验收。
