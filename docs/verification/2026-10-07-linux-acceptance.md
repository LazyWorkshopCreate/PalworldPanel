## 发现与修复

1. host 网络容器无 PortBindings，端口扫描空引用：安全处理空映射。
2. Linux 新目录不存在，DriveInfo 失败：检查存在的父目录所在磁盘。
3. 旧 UDP 通配映射和缺少 query 端口误拒绝：允许受控接管的既有映射，新建模板与管理回环仍严格校验。
4. LAN HTTP 缺少 crypto.randomUUID：增加 getRandomValues UUID v4 回退，实际网页动作验证成功。
5. 维护恢复重复申请已运行实例完整内存限额：未增限额的维护沿用原分配；新建、显式启动、增加限额仍检查实时可用内存。并发回归通过。
6. 游戏停服重写 INI 数字格式导致 SourceDrift：版本化参数指纹保留密码、未知字段及其他段的真实变更检测。旧指纹仅在原字节仍匹配且无活动任务时升级；变化来源保持阻止。再次接管后停启和清理回归通过。

第 5 项曾使第一正式实例定时备份后的恢复启动失败，任务 `example-identifier`。保留恢复点、配套回退后通过启动任务 `example-identifier` 恢复，核实原世界健康。该失败没有记录成成功。
