# ADR-014：游戏 UDP 通配绑定

日期：2026-10-13。状态：已采纳。关联：REQ-03 / REQ-11、W06 / W14。

## 背景

新建模板复用了面板 Web 的 LAN 绑定地址，宿主回环地址无法访问游戏端口。Web 管理入口的来源限制与游戏端口发布职责不同。

## 决策

正常部署的新建实例游戏 UDP 显式发布到 `0.0.0.0:<宿主游戏端口>:8211/udp`，同时支持宿主回环和 LAN 访问。面板 Web 继续使用指定 LAN 接口与来源白名单；REST 继续仅回环，RCON 关闭。查询 UDP 保持原指定 LAN 接口，不随游戏端口扩大。

Docker Desktop 隔离验证模式继续仅回环发布，避免测试服务进入真实网络。已接管实例保留原映射；旧版面板创建的 LAN 游戏映射允许读取，不能仅因升级而自动重建全部实例。新模板写入时采用通配游戏映射。

## 后果与验证

游戏 UDP 可接受宿主各 IPv4 接口上的流量；访问范围由宿主网络策略决定，不扩大管理 API 权限。端口分配仍保守排除宿主任何地址上的同号占用。模板校验同时覆盖新通配映射、旧 LAN 模板兼容和管理接口通配拒绝。

本地监听与 UDP 数据到达不能证明真实玩家入服。当前实例变更须保存、离线备份和受控重建；实际证据见[验证记录](../verification/2026-10-13-game-udp-binding.md)。
