# ADR-010：存档编辑只移动玩家文件

日期：2026-10-10。状态：已替代。由 [ADR-011](011-world-and-save-data.md) 替代。关联 REQ-22 / W26。

## 背景

管理员需要处理单个玩家的存档，但当前专用服务器存档使用会随游戏版本变化的压缩和自定义数据。完整改写角色或帕鲁没有官方字段规范，专有压缩也不能随面板分发。错误写回会破坏世界引用。

## 决策

第一版只提供存档组成查看，以及停服、备份后把选定玩家 `.sav` 移出世界目录。不解码或重写 `Level.sav`。`PlM` 和其他不能证明可逆的容器只展示原因。隔离后的实例保持停止，回退使用该任务的受保护恢复点。

## 备选

在面板内重写等级、物品和帕鲁需要版本化属性写入，并在每种游戏版本上证明未改字节保持不变。当前没有这个验证基础。把外部解码程序带入仓库会引入不能分发的压缩实现。允许上传任意 `.sav` 替换同样无法证明它和当前世界引用一致。

## 后果

玩家隔离不是完整的角色删除。世界里的帕鲁、基地和公会数据仍保留，玩家可能以新角色进入。以后若要编辑字段，必须另开需求，并带上该游戏版本的往返证据。

## 验证边界

合成容器和文件移动可以在单元测试中证明。本决策不证明真实游戏会如何对待被移走的玩家，也不证明当前生产存档的压缩标记。
