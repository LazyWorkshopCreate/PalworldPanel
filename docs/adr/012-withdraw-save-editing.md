# ADR-012：撤销存档数值编辑

日期：2026-10-10。状态：已采纳。关联：REQ-23 / W27。替代 [ADR-011](011-world-and-save-data.md)。

## 背景

ADR-011 把连接控制和存档数值分开，并只允许改写 zlib 容器里能唯一定位的整数。当前专用服务器存档使用 `PlM`。这种压缩不能随面板分发，面板不能解开后证明改写仍然可被游戏读取。因此数值编辑对真实世界没有作用。

## 决策

移除存档数值编辑。删除“存档”页、`save-fields`、`edit-save` 和对应的属性查找与写回。面板不修改存档正文。

世界管理保留：运行时通过游戏回环接口踢出、封禁和解除封禁；停止时只改本实例 `banlist.txt`；隔离玩家文件仍在停服和受保护备份之后进行。世界页可以列出玩家存档，只用于选择要隔离的文件。

## 备选与取舍

保留一个只会拒绝 `PlM` 的存档页，会让管理员以为可以改数值。引入专有解压缩库或 GPL 解码器，超出面板可分发和许可边界。继续只改早期 `PlZ` 存档，不能覆盖现在的专用服务器世界。

## 结果与验证

踢出、封禁、解除封禁和玩家隔离仍按 REQ-23 实现。旧的 `/instances/{id}/saves` 地址不再是实例页签。撤销前的数值编辑验收留在归档，不再作为现行证据。
