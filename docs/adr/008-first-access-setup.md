# ADR-008：首次访问网站设置管理员密码

日期：2026-10-06。状态：已采纳。关联 REQ-15 / W16 / W17；修订 ADR-005 的 Windows 管理员初始化入口。

Windows 初始化仍由管理员明确指定监听地址、精确内网 IP 白名单、Docker Desktop 账户和端口，准备主密钥、私有目录及防火墙；不再要求面板管理员密码。初始化生成持久的待设置管理员标记并开启 allowWebSetup，服务只接受这类显式标记。文件丢失、损坏或已初始化不会自动变成待设置状态；既有账号保留。

网站首次访问显示账号 admin、密码和确认密码。密码要求 16–128 字符，后端存框架密码哈希，禁止输出明文。GET /api/v1/setup 返回待设置状态与随机令牌；POST 继续经过来源白名单和严格同源校验，并验证令牌、重复密码、一次性状态及文件锁。成功写入后关闭初始化入口，进入登录页面。设置入口不能重置现有账号；不提供公开注册或默认密码。

首次访问只允许已明确加入白名单的管理员设备。多个请求竞争时仅一个成功，另一个冲突；重启根据持久标记决定状态。HTTP/TLS 策略以 ADR-007 为准。Linux 原有 CLI 初始化继续支持，不自动变更当前演示账号。

验证见 [Windows 验证](../verification/2026-10-06-windows-deployment.md)，操作见 [Windows 手册](../operations/2026-10-06-windows-deployment-r4.md)。
