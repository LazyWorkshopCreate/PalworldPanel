# ADR-009：安装模式与完整程序目录交换

日期：2026-10-06。状态：已采纳。关联 REQ-15 / W17；替代逐文件覆盖的程序升级方式，保留 ADR-005 的服务、实例隔离和数据备份要求。

安装向导仅有“重新配置”和“仅升级程序”两种模式。没有配置时默认重新配置；已有配置时默认仅升级。重新配置输入监听 IP、端口、逐项 IP 白名单、Docker Desktop Windows 账户，保留已有管理员密码、主密钥、数据库、实例目录和备份；首次安装准备待设置标记，密码仍通过网站设置。仅升级要求已有配置，不写配置、秘密或防火墙，不要求 Docker 引擎运行。

程序先写入与安装目录同级的唯一 .stage-* 目录，完整写入后才将旧目录移为 .previous-* 并将暂存目录移到正式路径。服务在交换前停止，任务在停止前后核实，配套状态/密钥先备份。程序目录和数据目录须独立，根路径、越界暂存、链接、程序目录内的运行数据均拒绝。不得递归清空或覆盖旧目录；旧目录作为回退材料保留，活动目录没有旧版本残留。

交换日志位于 ProgramData/PalworldPanel/installer，记录目录和阶段。后续注册/配置失败时回退程序目录，重新配置失败尽力恢复配置、ACL 与原防火墙；不能恢复的项目明确报错并保持服务停止。日志或移动中断须人工核实，不自动猜测恢复。升级不能承诺数据库 schema 反向兼容，服务启动仍须显式执行。

卸载器和日志置于程序目录之外，不参与程序目录交换。卸载前核对程序目录无运行数据和链接，再移除服务/程序；世界、密钥、状态和备份保留，旧程序归档不自动删除。

目录交换/回退在独立合成目录实测，管理员防火墙、SCM 与完整向导安装尚未验收。证据见 [Windows 验证](../verification/2026-10-06-windows-deployment.md)。
