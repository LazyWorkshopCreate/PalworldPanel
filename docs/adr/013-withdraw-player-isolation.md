# ADR-013：撤销玩家存档隔离

日期：2026-10-11。状态：已采纳。关联：REQ-23 / W27。替代 [ADR-012](012-withdraw-save-editing.md) 中保留玩家文件隔离的部分。数值编辑仍然撤销。

## 背景

玩家存档隔离只把 `Players/{编号}.sav` 移出世界，不改 `Level.sav`。当前存档使用不能随面板分发的压缩，面板不能同时改掉世界里的角色和据点引用。玩家用同一个编号再连接时，游戏会写一份新角色并改写世界，客户端停在读条，服务器却已经把连接算作进入。

## 决策

删除玩家存档隔离。去掉任务 `isolate-player`、世界页的隔离操作，以及隔离副本列表。面板不移动、不删除玩家存档。

世界管理仍保留踢出、封禁、解除封禁，以及玩家列表。列表可以展开查看仍在世界目录中的存档文件，不能据此移出文件。

## 备选与取舍

继续只移走角色文件，会把世界留在客户端无法读完的状态。在专有压缩里改写 `Level.sav` 超出面板可分发的边界。已经移出的副本留在原隔离目录，不由这次删除自动擦掉。

## 结果与验证

踢出、封禁和解除封禁仍按 REQ-23 实现。旧的隔离任务不再接受。实例目录隔离清理是另一项操作，继续保留。
