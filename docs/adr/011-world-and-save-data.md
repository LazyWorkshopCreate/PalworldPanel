# ADR-011：连接控制与存档数值分开

日期：2026-10-10。状态：已替代。由 [ADR-012](012-withdraw-save-editing.md) 替代。关联 REQ-23 / REQ-24 / W27 / W28。替代 [ADR-010](010-save-editing.md)。

## 背景

允许谁连接，和修改存档里的数值，是两件不同的事。封禁、踢出和移出玩家文件改变的是成员关系。科技点等数值才是存档数据。先前把移出玩家文件称为存档编辑，不能覆盖管理员要改的数据，也会把成员处理和数值修改混在同一页。

## 决策

世界管理使用官方回环接口和本实例 `banlist.txt` 控制连接，并保留停服备份后的玩家文件隔离。存档编辑只在 zlib 容器里定位允许的定长整数并替换这几个字节。专有压缩和不能完整解析的结构拒绝写入。不修改公共封禁地址，不编辑帕鲁、物品、公会或坐标。

## 备选

继续只提供文件隔离，无法满足数值修改。完整重写角色和帕鲁仍没有可分发的当前压缩解码和版本化字段证明。

## 后果

当前游戏若写出专有压缩，数值编辑会明确拒绝，而封禁和踢出仍然可用。隔离玩家文件不会自动封禁，也不会删除世界里的引用。

## 验证边界

合成存档和封禁列表示例可以在单元测试里证明。真实游戏是否接受修改后的科技点，以及运行中的封禁接口，这次没有连接游戏进程。
