# ADR-006：白名单内未登录只读仪表盘

日期：2026-10-06。状态：已采纳，用户明确要求未登录可看仪表盘、登录后才能操作。扩展 ADR-002 的登录展示契约，IP 白名单与全部管理认证保留。对应 REQ-01 / REQ-07 / W04 / W05。

## 决策与边界

只开放 GET /api/v1/dashboard 的独立投影：宿主指标及实例名称、运行状态、玩家/FPS/CPU/内存、时间/过期标记。它仍受精确内网 IP 白名单、同源策略和 no-store 控制，拒绝源不能看到匿名数据。匿名页面不读取管理模型；设置、密码、路径、端口、日志、任务、审计、发现、备份及导出仍需认证，写操作继续校验 Origin/认证/CSRF。

仪表盘共享 5 秒缓存，单次最多 4 路采样，8 秒截止，失败保留未知或过期，防止多个未登录访客重复触发无限 Docker/REST 查询。前端完成后每 5 秒轮询，卸载取消请求；数据故障不阻止登录。登录按钮打开弹窗，成功进入管理页；取消返回焦点，注销及会话过期回到只读页。菜单右侧排列。

不把管理 GET 全部 AllowAnonymous，不通过隐藏按钮代替后端鉴权。既有 Linux/Windows 权限、实例隔离和恢复流程不变。实际测试见 [验证记录](../verification/2026-10-06-desktop-implementation.md)，现行需求为导航选择的 r3。
