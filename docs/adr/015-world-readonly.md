# ADR-015 世界密码限定的只读访问

日期：2026-10-14。状态：已采纳。关联：REQ-24 / W28。

## 背景

用户要求凭世界 Id 与游戏连接密码查看实例详情及下载备份。已有匿名仪表盘仅提供状态，完整管理备份含敏感运维数据。

## 决策

增加独立的世界只读会话，使用已应用游戏密码，不赋予管理身份；保留内网白名单。空密码和歧义世界关闭访问。下载仅提供指定世界 .sav ZIP，避免完整运维备份泄漏。固定会话期限，每次核对密码与世界，重启失效。

## 备选与后果

拒绝复用管理员 cookie 或直接匿名返回实例模型；拒绝用游戏密码解密完整运维备份。独立分享密码可更细化权限，但增加管理成本，本期采用用户指定游戏密码。掌握游戏密码的玩家均能取得世界和玩家存档；此权限是本需求明确范围，页面予以说明。游戏密码较弱时仍依赖白名单和尝试限制，未来开放外网须另立需求与授权。
